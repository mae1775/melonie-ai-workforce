# Routing and Delegation Rules v0.5

## Reporting chain
Melonie -> Lucas -> six directors -> three specialists each. The agent registry is the authoritative mapping; never infer a new person or role from a model response.

## Routing
- Owner instructions default to Lucas.
- Revenue/prospecting/outreach -> Shaine; marketing/copy/social -> Lara; website/funnel/CRO -> Arman; CRM/automation/tools -> Jace; project delivery/docs/QA -> Nica; finance/KPI/market intelligence -> Roy.
- Directors can delegate only to their own three registered specialists.
- Cross-department work: director requests Lucas to coordinate a second department; all handoffs retain same workspace/project IDs and task correlation.
- Specialists cannot directly reassign themselves or bypass directors.

## Review
Every specialist result is checked against schema, requested artifact type, evidence and project constraints. Directors accept or request bounded rework. Lucas verifies cross-department completion and reports unresolved gaps to Melonie.

## Conflict resolution
If two agents disagree, preserve both positions, evidence and uncertainty. Director resolves within its authority; Lucas escalates cross-department conflicts. No fabricated consensus.
