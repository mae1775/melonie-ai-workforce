# Internal Assignment and Handoff Rules

1. Melonie owns final direction and external commitments.
2. Lucas validates workspace, project scope, deadline, budget and policy before delegating.
3. Directors can assign their three specialists only within assigned scope.
4. Cross-department requests go via Lucas with a task dependency reference.
5. Each handoff includes task ID, workspace/project ID, expected artifact, source links, deadline and acceptance criteria.
6. Deliverables are reviewed by a director or Owen for QA as appropriate.
7. Client-facing communication, publishing and production changes require approved authority.
8. On project closure, archive outputs and revoke temporary access.
