# v1.4 Offline Execution Engine
This release preserves previous artifacts and adds `20-Execution-Engine/` with a deterministic local execution simulation and automated tests. It deliberately **does not** implement real autonomy or connect services. See `20-Execution-Engine/README.md` and `16-Delivery/DEPLOYMENT-GATES.md` for limitations.
